# ABHYAAS — ONL Trade Activation & GTM Intelligence

Static HTML snapshot packaged for GitHub Pages.

## Publish
1. Extract this ZIP.
2. Upload `index.html`, `.nojekyll`, and `README.md` to the root of your GitHub repository (not inside a subfolder).
3. In the repository, open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Wait for GitHub Pages to finish deployment and use the URL shown on the Pages settings page.

## Notes
This is a static snapshot with demo/sample data, not a live-connected service. Interactions that depend on a backend or persistence will not be saved server-side.
